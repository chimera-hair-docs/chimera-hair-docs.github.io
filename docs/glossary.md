# 用語集

この説明書と、キメラヘアマスターの画面に出てくる言葉の意味です。

## キメラヘアマスターの言葉

| 言葉 | 意味 |
|---|---|
| キメラヘア | 別々のアバターや髪の素材から持ってきた髪を、組み合わせて作った髪型のことです |
| 髪 | 組み合わせる髪のオブジェクト1つ1つのことです（前髪、後ろ髪、アホ毛など）。画面では「Renderer」「髪パーツ」と書かれている所もあります |
| パーツ（UVアイランド） | 1つの髪の中の、毛束などのひとかたまりのことです。「パーツ変形」で選ぶ単位で、「UV配置」で並べる単位です |
| セットアップウィンドウ | 「キメラヘアマスター > ウィンドウを開く」で開くウィンドウです。最初の設定をまとめて行います |
| 基準マテリアル | 質感（光沢・影など）をそろえる元にするマテリアルです |
| プレビュー用マテリアル | 基準マテリアルをもとに、キメラヘアマスターが作るマテリアルです。「マテリアル設定」で編集します |
| メッシュ統合 | 髪のメッシュとテクスチャを1つにまとめることです |
| 色合わせ | 髪の陰影を残したまま、選んだ色にそろえることです |
| タブ | Inspectorの真ん中にある「基本」「色合わせ」「形と影」「変形」の切り替えです。押すと、その設定が出ます |
| 見出しのチェック | 「影の付き方をそろえる」「FakeShadow設定」の見出しの左にあるチェックです。その機能のON/OFFを切り替えます |
| 診断 | タブの下の「診断」欄で［診断］を押すと、設定の見落としや、直すと見た目がよくなりやすい所を調べて出します |

## Unity・VRChatの言葉

| 言葉 | 意味 |
|---|---|
| Hierarchy | Unityの画面の、シーンにあるオブジェクトの一覧です |
| Inspector | Unityの画面の、選んだオブジェクトの設定が出る所です |
| Sceneビュー | Unityの画面の、シーンを見ながら作業する所です |
| アップロード時（ビルド時） | アバターをVRChatにアップロードするときです。Playモードに入ったときも同じ処理が行われます。画面のメッセージでは「ビルド時」と書かれています |
| プレビュー | アップロードしなくても、結果をSceneビューで確かめられるしくみです。シーンの元の髪は変わりません |
| NDMF | アップロード時に、アバターを自動で加工するためのしくみです。キメラヘアマスターやModular Avatarが使っています |
| Undo | 直前の操作を取り消すことです。キーボードのCtrl+Zで行えます |
| Renderer | 見た目を表示する部品です。髪のメッシュには、SkinnedMeshRendererが付いています |
| SubMesh | 1つのメッシュの中で、マテリアルごとに分かれた部分です。画面では「SubMesh 0: マテリアル名」のように出ます |
| マテリアル | 色や質感の設定です。キメラヘアマスターは、lilToonのマテリアルに対応しています |
| テクスチャ | 髪の色や模様が描かれた画像です |
| UV | テクスチャのどこを、メッシュのどこに貼るかの情報です |
| アトラス | 複数のテクスチャを1枚の画像にまとめたものです |
| マスク | 白と黒で「効かせる所・効かせない所」を塗り分けた画像です |
| ノーマルマップ・AOマップ | 表面の凹凸や、すき間の暗さを表す画像です |
| マットキャップ | 光沢やつやを、画像で手軽に表すしくみです |
| 輪郭線 | lilToonの、メッシュのふちに線を描く機能です。lilToonでは、輪郭線のありなしでシェーダーが変わります |
| Blendshape | メッシュの形を、0〜100の値で変えられるしくみです（シェイプキーとも呼びます） |
| PhysBone | 髪などを揺らすための、VRChatの部品です |
| Probe Anchor | メッシュの明るさ（ライティング）を計算するときの基準になる位置です |
| Bounds | メッシュを描く範囲の箱です。小さすぎると、カメラの角度によってメッシュが消えます |
| ステンシル | 「ここにだけ描く」を決めるための、シェーダーのしくみです。FakeShadowで使います |
| Normal Bias | ライトの影の設定の1つです。メッシュ自身に影のちらつきが出ないように、影を作る形を少し内側に縮める量です |
| 圧縮形式（DXT1・BC7・ASTC） | テクスチャを小さくする方法です。BC7やASTC 4x4は画質がよく、DXT1は容量が小さくなります |
| VCC・ALCOM | VRChat用のプロジェクトとツールを管理するアプリです。キメラヘアマスターはこれで追加します |
