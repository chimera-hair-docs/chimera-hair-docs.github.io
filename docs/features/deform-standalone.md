# メッシュ変形（単体で使う）

キメラヘアマスターを使っていない髪や小物の形を、[メッシュ変形](mesh-deformation.md)と同じ操作で直します。色合わせやメッシュ統合は使わず、形だけを直したいときに使います。

:::tip[こんなときに使います]
- 色はそのままで、髪の形だけ直したい
- 髪以外の小物（アクセサリーなど）の形を直したい
:::

最初の手順は[メッシュ変形だけ使う](../getting-started/deform-only.md)にもまとめています。

## 付け方

次のどちらかで、「CHM - メッシュ変形機能」のコンポーネントを付けます。

- Hierarchyで直したいオブジェクトを右クリックし、「CHM - メッシュ変形を追加」を選びます。
- 「キメラヘアマスター > メッシュ変形」でウィンドウを開き、「対象Renderer」に直したいものを入れて［セットアップ］を押します。

![「キメラヘアマスター > メッシュ変形」で開くウィンドウ（「対象Renderer」と［セットアップ］）](/img/chm/standalone-1.png)

付けられるのは、SkinnedMeshRendererか、MeshFilterが付いたMeshRendererです。

次のときは付けられません（理由が表示されます）。

- その髪をキメラヘアマスターが対象にしている（キメラヘアマスターのInspectorのタブ「変形」で直してください）
- その髪にすでにメッシュ変形が付いている

## キメラヘアマスターのメッシュ変形との違い

| | キメラヘアマスターのメッシュ変形 | 単体のメッシュ変形 |
|---|---|---|
| 直せるもの | キメラヘアマスターの対象の髪 | 付けたオブジェクト1つ |
| MeshRenderer（動かない小物） | 使えません | 使えます |
| Blendshape として出力 | 使えます | SkinnedMeshRendererのときだけ使えます |
| 色合わせ・メッシュ統合・エクスポート | あります | ありません（変形したメッシュの保存だけです） |

画面と操作は同じです。[メッシュ変形](mesh-deformation.md)を見てください。

:::caution
同じ髪を、キメラヘアマスターと単体のメッシュ変形の両方で変形すると、アップロード時に変形が二重にかかります。キメラヘアマスターのタブ「変形」に警告が出たら（「診断」欄で［診断］を押したときにも出ます）、どちらか一方にしてください。
:::
