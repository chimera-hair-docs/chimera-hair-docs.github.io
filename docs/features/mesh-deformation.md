# メッシュ変形

組み合わせた髪の位置や形のずれを、Sceneビューで直します。元のメッシュは変わらず、直した形はアップロード時に反映されます（Playモードに入ったときも同じです）。

:::tip[こんなときに使います]
- 髪が頭に埋まる・浮いている
- 毛束どうしが重なったり、すき間があいたりしている
- 髪のシルエットを少し変えたい
:::

**場所**：Inspectorのタブ「変形」。変形した髪があると、タブの名前の下に「N本変形あり」と出ます。

:::info
キメラヘアマスターを使っていない髪や小物を直したいときは、[メッシュ変形（単体で使う）](deform-standalone.md)を使います。画面と操作はこのページと同じです。
:::

## 使い方

1. 「対象Renderer」で、直す髪を選びます（対象の髪が2つ以上のとき）。
2. 直し方のボタンを押します。編集が始まります。
3. Sceneビューでクリックして選び、ギズモで動かします。
4. 押しているボタンをもう一度押すと、編集が終わります。

| ボタン | 押した後の表示 | 向いている直し方 |
|---|---|---|
| パーツ変形 | ■ パーツ変形中（水色） | 毛束などのパーツ（UVアイランド）ごとに、まとめて動かす・回す・大きさを変えます |
| 頂点変形 | ■ 頂点変形中（オレンジ） | 頂点を選んで細かく動かします。まわりもなめらかについてきます |
| 全体の形を調整 (ラティス変形) | ■ ラティス編集中（緑） | 髪全体を囲むラティス（かご）の制御点を動かして、シルエットを大まかに変えます |

![Inspectorのタブ「変形」（「対象Renderer」と、直し方のボタン3つが見えるところ）](/img/chm/deform-4.png)

別のボタンを押すと、直し方が切り替わります。編集中に「対象Renderer」を変えると、同じ直し方のまま、その髪の編集に移ります。

次のときは、編集が自動で終わります。

- 別のオブジェクトを選んだとき
- Playモードに入るとき
- メッシュの保存や、［Prefab出力］などのエクスポートをしたとき
- ほかのタブに切り替えたとき
- 一番上の「有効」を変えたとき

## Sceneビューでの操作

Sceneビューの右下に、今の直し方の操作の一覧が出ます。

| 操作 | パーツ変形 | 頂点変形 | ラティス |
|---|---|---|---|
| クリック | パーツを選ぶ | 頂点を選ぶ | 制御点を選ぶ |
| Ctrl＋クリック | 選択に足す・外す | 選択に足す・外す | 選択に足す・外す |
| Shift＋クリック | 選択に足す | 選択に足す | 選択に足す |
| ドラッグ | — | 四角で囲んで選ぶ | 制御点を自由に動かす |
| W・E・R | 移動・回転・スケール | 移動・回転・スケール | — |
| 選んだ後 | ギズモで動かす | ギズモで動かす | XYZ軸ハンドルで動かす |

- 頂点変形では、マウスを乗せた頂点が強調されます。
- 頂点変形で、ギズモをドラッグしている最中にマウスホイールを回すと、「影響範囲」が変わります。

## 選んだ頂点をふくらませる・なめらかにする

パーツ変形・頂点変形で何か選ぶと、「選択中の頂点ツール」が出ます。

| 項目 | 説明 |
|---|---|
| 影響頂点数 | 今の設定で動く頂点の数です |
| 収縮 ← → 膨張 | 選んだ頂点を、表面に対して外側へふくらませたり、内側へ縮めたりします。頭に埋まった髪を少し浮かせるのに便利です |
| スライダーを0にリセット | 今のふくらみ・縮みを取り消します |
| スムージング | 選んだ頂点をまわりに近づけて、なめらかにします。何回か押すと、よりなめらかになります |

![「選択中の頂点ツール」（「収縮 ← → 膨張」のスライダーと［スムージング］が見える範囲）](/img/chm/deform-9.png)

## 左右対称に直す（対称編集）

頂点変形とラティスの編集中に使えます。「X (左右)」「Y (前後)」「Z (上下)」のどれか1つを押すと、反対側も同じように動きます。

- 対称の面は、初めはメッシュの真ん中に置かれます。「オフセット」の数値か、Sceneビューに出る面のハンドルで動かせます。
- 同時に使えるのは、1つの向きだけです。
- 対称になるのは、移動と膨張・収縮だけです。回転・スケール・スムージングは片側だけにかかります。

:::caution
「X」「Y」「Z」はメッシュ自身の向きです。髪のデータによっては、Unityの上下（Y）とは違う向きになります。押したら、Sceneビューに出る面の位置で確かめてください。
:::

![対称編集をONにしたSceneビュー（対称の面が見えるところ）](/img/chm/deform-7.png)

## 詳細設定

パーツ変形・頂点変形の編集中に、「詳細設定」を開くと出ます。

| 項目 | 初期値 | 出るとき | 説明 |
|---|---|---|---|
| 影響範囲 (m) | 0.05 | 頂点変形 | 選んだ頂点のまわりの、どこまでを一緒に動かすかです |
| 距離減衰 | スムーズ | 頂点変形 | 影響範囲の端に向かって、動きをどう弱めるかです（均一・直線・スムーズ・中心優先） |
| 距離の扱い | 空間上の距離 | 頂点変形 | 「つかんでいる表面の距離」にすると、すぐ近くにある別の毛束が一緒に動きにくくなります |
| 背面カリング | ON | いつも | こちらを向いていない頂点を表示せず、選べないようにします |
| Z-test(遮蔽非表示) | ON | いつも | ほかのメッシュの裏に隠れた頂点を表示せず、選べないようにします |

:::info
詳細設定はキメラヘアマスターに保存されません。Unityを開き直すと、初期値に戻ります。
:::

## ラティス設定

ラティスの編集中は、ラティスの細かさを「X分割」「Y分割」「Z分割」（1〜5、初期値は2）で変えられます。変えても、それまでの変形は残ります。

［ラティス変形前に戻す］を押すと、ラティスで行った変形をすべて取り消します。

## 陰影の調整

変形した髪があると出ます。

| 項目 | 初期値 | 説明 |
|---|---|---|
| 形に合わせる強さ | 0 | 0で元の髪の陰影のまま、1で変形した形に合わせて陰影を付け直します |

大きく形を変えた所の影が不自然なときに上げてください。大きく伸ばした所は、上げるとムラが出ることがあります。

![「陰影の調整」の「形に合わせる強さ」](/img/chm/deform-11.png)

## 変形のリセット

「変形のリセット」を開くと、次のボタンがあります。どちらも確認が出て、Undo（Ctrl+Z）で戻せます。

- ［この髪の変形をリセット］：選んでいる髪の変形を全部消します。
- ［すべての変形をリセット］：すべての髪の変形を消します。

## 変形したメッシュを保存する（出力）

選んでいる髪を変形していると、「出力」が出ます。

| 項目 | 説明 |
|---|---|
| Blendshape として出力 | ONにすると、元の形はそのままで、変形をBlendshapeとして足したメッシュを保存します。Blendshapeの値（0〜100）で、変形のかかり具合を変えられます |
| Blendshape 名 | 足すBlendshapeの名前です（初期値は「CHMDeform」）。同じ名前があると、自動で別の名前になります |
| ［メッシュを保存］ | 変形したメッシュを、ファイルに保存するだけです |
| ［メッシュを保存して入れ替え］ | 保存したあと、確認して、髪のメッシュを保存したものに入れ替えます。変形のデータはメッシュに焼き込まれて消えます。Undo（Ctrl+Z）で戻せます |

![「出力」（「Blendshape として出力」と［メッシュを保存］［メッシュを保存して入れ替え］が見える範囲）](/img/chm/deform-10.png)

:::caution
「Blendshape として出力」が効くのは、このボタンと、「エクスポート」の［キメラヘアマスターを元の髪に反映する］のときだけです。そのままアップロードすると、変形は形そのものに焼き込まれます。Blendshapeとして残したいときは、先に［メッシュを保存して入れ替え］を押してください。
:::
