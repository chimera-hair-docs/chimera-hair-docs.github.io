# 色の細かい調整

[色合わせ](color-matching.md)でそろえた後に、髪ごとの違いを直すための設定です。

**場所**：Inspectorのタブ「色合わせ」の下のほう。「個別の明るさの調整」「塗り感統一」「色合わせ無視(マスク)」はそのまま並び、「ぼかし・シャープ調整」「色が合わないとき？」は「詳細設定」の中にあります（どれも初めは閉じています）。

「塗り感統一」がONのときや、「詳細設定」の中で何かが効いているときは、見出しの後ろに「（使用中）」と出ます。

| 困りごと | 使う設定 |
|---|---|
| 一部の髪だけ明るい・暗い | [個別の明るさの調整](#個別の明るさの調整) |
| 一部の髪だけ線がくっきり・ぼんやりしている | [ぼかし・シャープ調整](#ぼかしシャープ調整)、[塗り感統一](#塗り感統一) |
| 髪飾りやインナーカラーなど、一部の色は変えたくない | [色合わせ無視(マスク)](#色合わせ無視マスク) |
| 色合わせしても、どうしても色が合わない髪がある | [色が合わないとき？](#色が合わないとき) |

## 個別の明るさの調整

髪ごとに明るさを直します。スライダーを右（＋）にすると明るく、左（−）にすると暗くなります。［リセット］で0に戻ります。

髪の名前をクリックすると、Hierarchyでその髪が光り、Sceneビューでもその髪に青い縞が2秒ほど重なります。どの行がどの髪かわからないときに使ってください。

![髪の名前をクリックしたときのSceneビュー（その髪に青い縞が重なっているところ）](/img/chm/fine-4.png)

:::tip
色合わせ後の明るさがほかの髪とずれている髪は、タブの下の「診断」欄で［診断］を押したときにも出ます。［ほかの髪に合わせる］を押すと、ずれが小さくなる値がこの欄に入ります（[診断](basic-settings.md#診断)）。
:::

![「個別の明るさの調整」を開いたところ（髪ごとのスライダーが並んでいる）](/img/chm/fine-1.png)

## 塗り感統一

お手本にした髪の塗りの感じ（線の細さ・塗りの濃淡）に、ほかの髪を寄せます。

| 項目 | 初期値 | 説明 |
|---|---|---|
| 有効化 | OFF | ONにすると、下の項目が使えます |
| お手本 Renderer | 一覧の先頭の髪 | 塗りの感じを合わせる元の髪です |
| 線の細さ強度 | 1 | 毛束の輪郭など、細かい描き込みをどれだけお手本に寄せるかです |
| 塗りの濃淡強度 | 1 | 影の付け方のメリハリを、どれだけお手本に寄せるかです |
| 対象スケール | 5 | 「細かい描き込み」と「濃淡」を分ける目安の毛束の太さです。ふだんは5のままで大丈夫です |

![「塗り感統一」を開いたところ（「有効化」「お手本 Renderer」と強さの項目が見える範囲）](/img/chm/fine-5.png)

## 色合わせ無視(マスク)

マスクの画像を使って、髪の一部だけ色合わせをしないようにします。髪飾り、インナーカラー、毛先のグラデーションなど、元の色を残したい所に使います。

- マスクの**黒い所は元の色のまま**になり、白い所は色合わせされます。
- マスクは、元の髪のテクスチャと同じ並び（元のUV）で作ります。
- 髪ごと、マテリアル（SubMesh）ごとに1枚ずつ入れられます。欄を空にすると、マスクを使わなくなります。
- 髪の名前を押すと、Sceneビューでその髪に青い縞が2秒ほど重なります。どの欄がどの髪かわからないときに使ってください。

### マスクを作る

［マスクを作成］を押すと、マスク作成支援ツールが開きます。Sceneビューで髪を塗ったり選んだりしてマスクを作り、保存すると、この欄に自動で入ります。

:::info
- マスク作成支援ツールは、キメラヘアマスターの「マスクツール同梱版」に入っています。単体版の人は、「塗って！選んで！マスク作れるやつ」（v1.1以上）でも使えます。v1.3より前のものでは、保存したマスクが自動では入らないので、自分で欄に入れてください。
- ［マスクを作成］を押すと、プレビューが止まります。マスクを保存したら、［プレビュー開始］を押してください。
:::

画像編集ソフトで描いたマスクを、この欄に入れてもかまいません。

![［マスクを作成］で開いたマスク作成支援ツールで、色を変えたくない所を塗っているところ](/img/chm/fine-7.png)

## ぼかし・シャープ調整

髪ごとに、テクスチャをぼかしたり、くっきりさせたりします。スライダーを左（−）にするとぼけて、右（＋）にするとくっきりします。

描き込みが細かい髪と、やわらかい塗りの髪を組み合わせたときに、塗りの感じを近づけるのに使います。

## 色が合わないとき？

元のテクスチャの色によっては、色合わせしても色が合わないことがあります。そのときは、元のテクスチャの色を目標の色に近づけた別のマテリアルを用意して、ここで元のマテリアルと入れ替えてください。入れ替えたマテリアルにも色合わせがかかります。

- 髪ごと、SubMeshごとに、今のマテリアルが入った欄が並んでいます。別のマテリアルを入れると入れ替わります。
- 髪の名前を押すと、Sceneビューでその髪に青い縞が2秒ほど重なります。
- 入れ替えは、その髪に直接反映されます（マテリアルのファイル自体は変わりません）。Undo（Ctrl+Z）で戻せます。

![「色が合わないとき？」を開いたところ（髪ごと・SubMeshごとのマテリアルの欄が並んでいる範囲）](/img/chm/fine-8.png)
