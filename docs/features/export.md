# エクスポート

キメラヘアマスターは、ふだんはアップロード時に自動で処理するので、エクスポートは必要ありません。次のようなときだけ、結果をファイルやPrefabとして出力します。

:::tip[こんなときに使います]
- キメラヘアマスターを外して、結果だけを残したい
- ほかのツールと組み合わせると、うまく動かない
- 色を合わせた髪を、別のアバターや別のプロジェクトでも使いたい
:::

**場所**：Inspectorのタブの下の「エクスポート」（どのタブを開いていても出ます）

出力のしかたは2つあります。

| 出力のしかた | 何ができるか | 元の髪 |
|---|---|---|
| [テクスチャ出力](#テクスチャ出力) | 色を合わせたテクスチャをPNGで出力して、元の髪のマテリアルに入れます | 書き換わります |
| [Prefab出力](#prefab出力) | 色合わせ・マテリアル設定・変形を反映した髪を、別のPrefabとして作ります | 変わりません（非表示にするだけです） |

![Inspectorの「エクスポート」を開いたところ（「テクスチャ出力」と「Prefab出力」が見える範囲）](/img/chm/export-1.png)

:::caution
どちらも、出力した後はキメラヘアマスターの「有効」が自動でOFFになります（二重にかからないようにするためです）。
:::

:::info
「影の付き方をそろえる」は、どちらの出力にも入りません。
:::

## テクスチャ出力

色合わせがONのときだけ出ます。

| 項目 | 初期値 | 説明 |
|---|---|---|
| テクスチャをマテリアルに適用 | ON | 出力したテクスチャを、元の髪のマテリアルのメインテクスチャに入れます |
| マテリアル設定を統一 | ON | 「マテリアル設定」の数値を、元の髪のマテリアルに上書きします |
| 変形も反映する | ON | メッシュ変形した形を、メッシュとして保存して髪に入れます（変形したときだけ出ます） |
| FakeShadowもセットアップする | ON | FakeShadowをシーンに直接セットアップします（FakeShadowが有効なときだけ出ます） |

［キメラヘアマスターを元の髪に反映する］を押すと、次のことをします。

- 元のテクスチャと同じフォルダに「{元のテクスチャ名}_CHM.png」を出力します（同じ名前のファイルがあれば上書きします）。
- 上のチェックに従って、元の髪のマテリアルとメッシュを書き換えます。
- キメラヘアマスターの「有効」をOFFにします。

:::caution
- **元の髪のマテリアルのファイルそのものが書き換わります。** 同じマテリアルを使っている、ほかのアバターの髪にも影響します。
- メッシュ統合がONのときは、統合はせずに、テクスチャの出力だけをします。メッシュ統合の設定はOFFになります。
- 変形したのに「変形も反映する」がOFFだと、確認が出ます。変形を反映しないと、キメラヘアマスターがOFFになるため、変形がなくなります。
- 押した直後なら、Undo（Ctrl+Z）で、髪のマテリアルとキメラヘアマスターを元に戻せます（出力したPNGはファイルとして残ります）。
:::

この欄のチェックは、このパソコンのUnityに保存されます。別のアバターや別のプロジェクトでも、同じ状態になります。

## Prefab出力

色合わせ・マテリアル設定・変形を反映した髪を、アバターから取り出したPrefabとして作ります。元の髪は書き換えません。

| 項目 | 初期値 | 説明 |
|---|---|---|
| マテリアル設定を統一 | ON | ONなら、基準マテリアルの設定をすべての髪のマテリアルにコピーします。OFFなら、それぞれの髪の元のマテリアル設定のままです |
| 元の髪を非表示にする（EditorOnly） | ON | 出力したPrefabと二重に見えないように、元の髪を非表示にして、アップロードから外します |
| 変形も反映する | ON | 変形した形を反映します（変形したときだけ出ます） |
| FakeShadowを含める | ON | FakeShadowの影をPrefabに入れます（FakeShadowを使っているときだけ出ます） |

［Prefab出力］を押して保存先を選ぶと、次のものを作ります。

- 色を合わせたテクスチャ「{元のテクスチャ名}_CHM.png」（元のテクスチャと同じフォルダ）
- マテリアルの複製「{元のマテリアル名}_CHM.mat」（元のマテリアルと同じフォルダ）
- 変形したメッシュ（「変形も反映する」がONのとき）
- 髪と、髪を動かすのに必要なものだけを残したPrefab

作ったPrefabは、アバターのすぐ下に置かれます。

:::info
- メッシュ統合はされません。髪は1つずつのまま出力されます。
- 出力した髪をアバターに追従させるには、Modular Avatarが必要です。Modular Avatarが入っていれば、Prefabに「MA Merge Armature」が自動で付きます。入っていないと警告が出るので、Prefabの中のArmatureを自分でアバターに合わせてください。
- 「FakeShadowを含める」がONのときは、顔はPrefabに入らないため、シーンのアバターの顔のマテリアルが、影を受ける設定を足した複製に差し替わります（Undo（Ctrl+Z）で戻せます）。
:::

「マテリアル設定を統一」以外のチェックは、このパソコンのUnityに保存されます。「マテリアル設定を統一」は、このキメラヘアマスターに保存されます。
