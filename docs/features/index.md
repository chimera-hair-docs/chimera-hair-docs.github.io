# やりたいことから探す

やりたいことから、使う機能を探せます。Inspectorの並び（タブ「基本」「色合わせ」「形と影」「変形」）は[Inspectorの見方と基本設定](basic-settings.md#inspectorの並び)にまとめています。うまくいかないときは、タブの下の「診断」欄の［診断］を押すか、[困ったとき](/troubleshooting)を見てください。

## 色を変えたい

| やりたいこと | 使う機能（Inspectorの場所） | ページ |
|---|---|---|
| 髪の色を1つの色にそろえたい | タブ「色合わせ」の「この色に変更」 | [色合わせ](color-matching.md) |
| 暗い所と明るい所で色を変えたい | タブ「色合わせ」の「詳細設定」の「計算方法」で、「色変換モード」をグラデーションにする | [色合わせ](color-matching.md#グラデーション) |
| 髪のテクスチャから色を拾いたい | タブ「色合わせ」の「テクスチャから色を選択」 | [色合わせ](color-matching.md#テクスチャから色を拾う) |
| 一部の髪だけ明るさを直したい | タブ「色合わせ」の「個別の明るさの調整」（「診断」欄の［ほかの髪に合わせる］でも直せます） | [色の細かい調整](color-fine-tuning.md#個別の明るさの調整) |
| 髪飾りやインナーカラーの色は変えたくない | タブ「色合わせ」の「色合わせ無視(マスク)」 | [色の細かい調整](color-fine-tuning.md#色合わせ無視マスク) |
| 塗りの感じ（くっきり・やわらか）をそろえたい | タブ「色合わせ」の「塗り感統一」、「詳細設定」の「ぼかし・シャープ調整」 | [色の細かい調整](color-fine-tuning.md#ぼかしシャープ調整) |

## 形や見た目を直したい

| やりたいこと | 使う機能（Inspectorの場所） | ページ |
|---|---|---|
| 髪が頭に埋まる・浮く・ずれるのを直したい | タブ「変形」 | [メッシュ変形](mesh-deformation.md) |
| 髪を左右対称に直したい | タブ「変形」の「対称編集」 | [メッシュ変形](mesh-deformation.md#左右対称に直す対称編集) |
| パーツを後から付けたような感じをなくしたい | タブ「形と影」の「影の付き方をそろえる」 | [影の付き方をそろえる](shading-unify.md) |
| 光沢や影の感じを髪ごとにそろえたい | 一番下の「マテリアル設定」 | [マテリアル設定](material-settings.md) |
| 髪の影を顔に落としたい | タブ「形と影」の「FakeShadow設定」 | [FakeShadow](fake-shadow.md) |
| キメラヘアマスターを使わない髪や小物の形を直したい | 「CHM - メッシュ変形機能」 | [メッシュ変形（単体で使う）](deform-standalone.md) |

## 軽くしたい・まとめたい

| やりたいこと | 使う機能（Inspectorの場所） | ページ |
|---|---|---|
| 髪のメッシュとマテリアルを1つにまとめたい | 「メッシュ統合」（セットアップのときに選ぶ） | [メッシュ統合](mesh-merge.md) |
| 見えない部分のメッシュを消したい | タブ「形と影」の「メッシュカット設定」 | [メッシュ統合](mesh-merge.md#メッシュカット設定) |
| テクスチャの画質や容量を変えたい | タブ「基本」の「テクスチャ設定」 | [テクスチャ設定](texture-settings.md) |

## 髪を足したい・外したい

| やりたいこと | 使う機能（Inspectorの場所） | ページ |
|---|---|---|
| 対象の髪を足したい・外したい・並べ替えたい | タブ「基本」の「対象Renderer」 | [Inspectorの見方と基本設定](basic-settings.md#対象renderer) |
| プレビューを止めたい・始めたい | 一番上の［プレビュー停止］［プレビュー開始］ | [Inspectorの見方と基本設定](basic-settings.md#プレビュー) |

## 結果をファイルやPrefabにしたい

| やりたいこと | 使う機能（Inspectorの場所） | ページ |
|---|---|---|

| 色を合わせた髪を別のPrefabにしたい | タブの下の「エクスポート」の「Prefab出力」 | [エクスポート](export.md#prefab出力) |
| 変形したメッシュをファイルに保存したい | タブ「変形」の「出力」 | [メッシュ変形](mesh-deformation.md#変形したメッシュを保存する出力) |
