# テクスチャ設定

キメラヘアマスターが色合わせやメッシュ統合で作り直すテクスチャの、画質と容量の設定です。

:::tip[こんなときに使います]
- グラデーションがブロック状にがたついて見える
- まとめたテクスチャの大きさ（解像度）を変えたい
- メッシュ統合したら、マットキャップや発光のマスクの位置がずれた
:::

**場所**：Inspectorのタブ「基本」の「テクスチャ設定」

![タブ「基本」の「テクスチャ設定」を開いたところ（メッシュ統合がONの状態）](/img/chm/tex-1.png)

## 設定項目

| 項目 | 初期値 | 出るとき | 説明 |
|---|---|---|---|
| 生成テクスチャの圧縮（PC） | 元と同じ | いつも | 作り直したテクスチャの圧縮のしかたです。「元と同じ（そのままの圧縮品質）」か「高画質（BC7）」を選べます |
| 生成テクスチャの圧縮（Quest） | 元と同じ | 色合わせ後のマテリアルがQuest用のシェーダー（VRChat/Mobile系）のとき | 「元と同じ（そのままの圧縮品質）」「高画質（ASTC 4x4）」「標準（ASTC 6x6）」から選べます |
| 解像度 | 2048x2048 | メッシュ統合がONのとき | まとめたテクスチャの大きさです（512〜4096） |
| ノーマルマップ解像度 | ×1 | メッシュ統合がONのとき | まとめたノーマルマップの大きさです。「解像度」に対して×1・×1/2・×1/4から選べます |
| AOマップ解像度 | ×1 | メッシュ統合がONのとき | まとめたAOマップの大きさです。選び方は上と同じです |
| アルファチャンネルを常に保持 | OFF | メッシュ統合がONのとき | ふだんはOFFのままにしてください（下を参照） |

:::tip
グラデーションがブロック状にがたつくときは、「生成テクスチャの圧縮（PC）」を「高画質（BC7）」にしてください。容量はDXT5と同じで、DXT1の2倍になります。
:::

- 元が圧縮していないテクスチャは、どれを選んでも圧縮しないままです。
- この設定は、「エクスポート」の［キメラヘアマスターを元の髪に反映する］と［Prefab出力］で作るPNGにも使われます。
- 「アルファチャンネルを常に保持」がOFFのとき、まとめたテクスチャが不透明なら、メモリを節約するためにアルファの無い形式（DXT1）で圧縮します。アルファを特別な用途に使うシェーダーのときだけONにしてください。

## マットキャップ/発光/反射/ラメ マスク

メッシュ統合がONのときだけ使えます。

元の髪のマテリアルで使っているマットキャップ・発光・反射・ラメのマスクは、統合するとテクスチャの並びが変わるため、そのままでは位置がずれます。ここで、統合後の並びに作り直した画像を作れます。

1. ［マスクテクスチャを生成］を押します。
2. 作られたマスクが一覧に並びます。使いたいマスクの［割り当て］を押すと、「マテリアル設定」のその欄に入り、その機能もONになります。

:::info
マスクは作るだけで、自動では割り当てません。必要なものだけ［割り当て］を押してください。画像を編集してから、自分で割り当ててもかまいません。
:::

- 作ったマスクは、プレビュー用マテリアルと同じフォルダの「{オブジェクトの名前}_Masks」に保存されます。作り直すと同じ名前で上書きするので、割り当て済みの欄はそのままです。
- 一覧の右の数字（512〜4096）で、そのマスクの大きさを変えられます。
- UVの配置や髪のマテリアルを変えた後は、「UV配置または素材が変更されています。マスクを再生成してください」と出ます。もう一度［マスクテクスチャを生成］を押してください。
- 元の髪にマットキャップの画像があるときは、「元のマットキャップ画像」にも［割り当て］が出ます。
