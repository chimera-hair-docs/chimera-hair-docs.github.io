# FakeShadow

髪が顔に落とす影（FakeShadow）を足します。lilToonのFakeShadowシェーダーを使います。

:::tip[こんなときに使います]
- 前髪の影が顔に落ちなくて、髪が浮いて見える
:::

**場所**：Inspectorのタブ「形と影」の「FakeShadow設定」

| OFF | ON |
|---|---|
| ![FakeShadowのOFFとONで、前髪の影が顔に落ちているかの比較（同じ角度で2枚）（OFF）](/img/chm/shadow-1-off.png) | ![FakeShadowのOFFとONで、前髪の影が顔に落ちているかの比較（同じ角度で2枚）（ON）](/img/chm/shadow-1-on.png) |

## 使い方

1. タブ「形と影」の「FakeShadow設定」の見出しのチェックをONにします。中が開きます。
2. 「顔のRenderer」に顔のメッシュを入れます。ONにしたときに空なら、アバターの中の「Body」（無ければ「body」）という名前のメッシュが自動で入ります。
3. 「影を受ける顔マテリアル」で、影を落としたい顔のマテリアルにチェックを入れます。
4. Sceneビューのプレビューで影を確かめながら、色や向きを調整します。

![「FakeShadow設定」を開いて、「顔のRenderer」と「影を受ける顔マテリアル」を設定したところ](/img/chm/shadow-2.png)

## 設定項目

| 項目 | 初期値 | 説明 |
|---|---|---|
| 顔のRenderer | （自動で入ります） | 影を受ける顔のメッシュです |
| 影を受ける顔マテリアル | 何も選ばない | 影を落とす顔のマテリアルです。1つ以上選んでください |
| 影を落とす髪 | 全部ON | OFFにした髪は影を作りません |
| 影の色 | 薄いピンク | 顔に落ちる影の色です |
| 影の向き | X 0.2・Y −0.2 | 影をずらす向きです |
| 影のずらし量 | 0.004 | 影をどれだけずらすかです（0〜0.05） |

「詳細設定」を開くと、次の項目もあります。

| 項目 | 初期値 | 説明 |
|---|---|---|
| ステンシル値 | 48 | 顔と影を組み合わせるのに使う番号です（1〜255） |
| 深度バイアス | X −1・Y −1 | 影を描く奥行きのずらし量です。ふだんはそのままで大丈夫です |

:::caution
顔がすでにステンシル（まつ毛を透かして見せる表現など）を使っているときは、「ステンシル値」をその設定に合わせてください。
:::

:::info
メッシュ統合がONのときは、統合した髪はまとめて影を作ります。「影を落とす髪」の選択は、統合されずに残る髪にだけ効きます。
:::

## 顔のマテリアルについて

アップロード時とプレビューでは、顔のマテリアルは複製したものに差し替えられて、影を受ける設定が足されます。元の顔のマテリアルは変わりません。

選んだ顔のマテリアルにステンシルの設定が無いと、「選択した顔マテリアルにステンシル設定がありません（lilToon系シェーダーのみ対応）。」と出ます。顔もlilToonのマテリアルにしてください。

## FakeShadow設定をエクスポートする

［FakeShadow設定をエクスポート］を押すと、アップロード時に行う設定を、シーンのアバターに直接行います。キメラヘアマスターを外して使いたいときや、ほかのツールと組み合わせてうまく動かないときに使います。

確認のメッセージが出て、［OK］を押すと次のことをします。

- 髪ごとに、子に影のオブジェクト（「{髪の名前} (CHM FakeShadow)」）を足します。
- 顔のマテリアルを、影を受ける設定を足した複製（「{元の名前}_CHMFakeShadowFace」）に差し替えます。
- 必要なら、髪のマテリアルの描画順（Render Queue）を直接変えます。同じマテリアルを使っている別のアバターにも影響します。
- 「FakeShadow設定」の見出しのチェックをOFFにします（二重にかからないようにするためです）。

どれもUndo（Ctrl+Z）で戻せます。
