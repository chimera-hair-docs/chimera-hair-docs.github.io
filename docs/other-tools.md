# ほかのツールと使う

キメラヘアマスターは、アップロード時にNDMFというしくみで処理します。NDMFを使うほかのツールとは処理の順番を決めてあるので、同じアバターで一緒に使えます。

## Modular Avatar

別のアバターから持ってきた髪は、Modular Avatarの「MA Merge Armature」などで今のアバターに着せてから、キメラヘアマスターの対象にしてください。

[Prefab出力](features/export.md#prefab出力)で出力した髪をアバターに追従させるときも、Modular Avatarを使います。Modular Avatarが入っていれば、Prefabに「MA Merge Armature」が自動で付きます。

アバターに「MA Mesh Settings」があるときは、メッシュ統合した髪の「メッシュ設定」の「設定モード」で、どちらの指定を使うかを選べます（[メッシュ統合](features/mesh-merge.md#設定モード)）。

## マスク作成支援ツール

[色合わせ無視(マスク)](features/color-fine-tuning.md#色合わせ無視マスク)と[メッシュカット設定](features/mesh-merge.md#メッシュカット設定)の［マスクを作成］、メッシュ統合がONのときの［マスクを編集する］で使います。

| 入っているもの | 使えるか |
|---|---|
| キメラヘアマスター（マスクツール同梱版） | 使えます（初めから入っています） |
| 「塗って！選んで！マスク作れるやつ」v1.3以上 | 使えます |
| 「塗って！選んで！マスク作れるやつ」v1.1・v1.2 | 使えます。ただし、［マスクを作成］で保存したマスクは自動では欄に入らないので、自分で入れてください |
| 「塗って！選んで！マスク作れるやつ」v1.0 | ［マスクを編集する］だけ使えます。［マスクを作成］を使うには更新が必要です |

ツールが入っていないときや古いときは、ボタンを押すと案内が出ます。

## Tocolo

キメラヘアマスターv1.6.5以上と、Tocolo v0.4.6以上の組み合わせなら、同じアバターで使えます。

| キメラヘアマスターの髪 | Tocoloの色変え |
|---|---|
| メッシュ統合がOFF | キメラヘアマスターで色を合わせた上に、Tocoloの色変えがかかります |
| メッシュ統合がON | かかりません（Tocoloに案内が出ます） |

キメラヘアマスターの髪のテクスチャは、Tocoloからは出力できません。

## ほかのツールのプレビュー中にエクスポートするとき

ほかのツールのプレビュー中は、髪や顔に、保存されない一時的なマテリアルが入っていることがあります。このまま［キメラヘアマスターを元の髪に反映する］［Prefab出力］［FakeShadow設定をエクスポート］を押すと、結果が正しく残らないので、メッセージが出て止まります。

そのツールのプレビューを止めてから、もう一度押してください。

## うまく動かないとき

ほかのツールと組み合わせてうまく動かないときは、キメラヘアマスターの結果を[エクスポート](features/export.md)してから、キメラヘアマスターを外して試してください。
