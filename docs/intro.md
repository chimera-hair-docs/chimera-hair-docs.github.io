# キメラヘアマスター

キメラヘアマスターは、別々のアバターや髪の素材から持ってきた髪を組み合わせた「キメラヘア」を、1つの髪型としてなじませるためのUnityのツールです。

## できること

| 困りごと | 使う機能 |
|---|---|
| 髪ごとに色や明るさが違う | [色合わせ](features/color-matching.md)：選んだ色に、髪の陰影を残したまま色をそろえます |
| メッシュやマテリアルが増えて重い | [メッシュ統合](features/mesh-merge.md)：髪のメッシュとテクスチャを1つにまとめます |
| 光沢や影の感じが髪ごとにバラバラ | [マテリアル設定](features/material-settings.md)：基準のマテリアルの設定にそろえます |
| 組み合わせた髪の位置や形がずれる | [メッシュ変形](features/mesh-deformation.md)：Sceneビューで髪の形を直します |
| パーツを後から付けたように見える | [影の付き方をそろえる](features/shading-unify.md)：髪全体の影の付き方を1つにそろえます |
| 髪の影が顔に落ちない | [FakeShadow](features/fake-shadow.md)：髪の影を顔に落とします |

どの機能も、シーンにある元の髪やマテリアルは書き換えません。結果はSceneビューのプレビューで確かめられ、アップロード時に自動で反映されます（Playモードに入ったときも同じです）。

## 必要なもの

- Unity 2022.3
- VRChat SDK（Avatars）
- NDMF 1.14.0以降（キメラヘアマスターを入れると一緒に入ります）
- 髪のマテリアルがlilToonであること

## インストール

1. ダウンロードしたファイルに入っている「キメラヘアマスター（…）をVCC・ALCOMに追加」を開きます。VCC（またはALCOM）に、キメラヘアマスターの取得先が追加されます。
2. VCC（またはALCOM）で、使いたいアバターのプロジェクトを開き、「キメラヘアマスター」を追加します。

| ダウンロードしたファイル | 開いたときの確認 |
|---|---|
| ![ダウンロードしたファイルの中の「キメラヘアマスター（…）をVCC・ALCOMに追加」と、それを開いたときのVCC（またはALCOM）の確認（ダウンロードしたファイル）](/img/chm/intro-3-file.png) | ![ダウンロードしたファイルの中の「キメラヘアマスター（…）をVCC・ALCOMに追加」と、それを開いたときのVCC（またはALCOM）の確認（開いたときの確認）](/img/chm/intro-3-vcc.png) |

![VCC（またはALCOM）のプロジェクトの画面で、キメラヘアマスターを追加するところ](/img/chm/intro-2.png)

追加するためのファイルは2種類あります。どちらか一方だけを追加してください。

| 種類 | 入っているもの |
|---|---|
| マスクツール同梱版 | キメラヘアマスターと、マスク作成支援ツール（色を変えたくない所などを塗るツール） |
| 単体版 | キメラヘアマスターだけ |

## 更新と削除

- **更新**：VCC（またはALCOM）のプロジェクトの画面で、キメラヘアマスターのバージョンを新しいものに変えます。変わった内容は[更新履歴](/changelog)にまとめています。
  - 1.xから2.0に更新しても、設定はそのまま使えます。Inspectorの並びが変わったので、場所がわからないときは[2.0への更新](troubleshooting/symptoms.md#20への更新)を見てください。
- **削除**：VCC（またはALCOM）のプロジェクトの画面で、キメラヘアマスターを削除します。シーンに付けたキメラヘアマスターのコンポーネントは「Missing」と表示されるので、Inspectorから外してください。
